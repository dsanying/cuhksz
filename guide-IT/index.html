IT 指南

2024-08-22T01:15:57.348Z2025-08-29T12:44:00.365Z1.3k5 分钟

完整 IT 手册请查看网址: https://itso.cuhk.edu.cn/student

简介

本篇文章包含基本的校园 IT 知识

CUHK(SZ)账号

账号是一串数字，也是你的学号。学校所有系统的账号与密码都是统一的。
本科生查询网址: https://ug-inquiry.cuhk.edu.cn/index.html
研究生和国际生的账号与密码会发送到个人邮箱里。

访问密码自助服务平台 (https://myid.cuhk.edu.cn/) 以便激活账号、修改密码、绑定密保手机/邮箱。

直接使用给你的账号与初始密码登录即可，不要点击”忘记密码”或者”解锁账号”

电子邮箱

每位同学都拥有一个学校邮箱，即”(学号)@link.cuhk.edu.cn”。
学生可以使用 CUHK(SZ)账号与密码登录学校邮箱。
例如:

邮箱账号: 120999999@link.cuhk.edu.cn
密码: 学校账号密码

登录方式:

  • 网页：https://outlook.office.com/
  • 电脑端: 推荐使用系统自带的 Outlook(new)直接添加邮箱或者下载 Office365 中的 Outlook 添加邮箱
  • 手机端: 任意邮箱软件选择 Exchange 类型，一般输入邮箱及密码即可自动添加(不要输入用户名等其它东西)

Office 365

要查看拥有的 Office 365 权限并安装相关应用，请访问 Office 365 账户门户，使用学校邮箱和密码进行登录。

校园卡

每位同学都将收到一张校园卡（学生卡），卡上有你的姓名、学号、照片和书院等信息。此卡可以在新生报到注册当天领取。
校园卡除了考试和进入游泳馆、功能房等部分场地外基本就没用了，千万不要往校园卡里充钱。
如需在别的地方使用(例如进出校门)可以使用电子校园卡(微信搜索小程序”港中深虚拟校园卡”)

校园网络

无线/有线网络

直接连接网络即可，在弹出的认证页面使用学校账号及密码登录即可。

如果没有弹出认证页面可以手动访问网址 10.10.10.10 。如果该网址无法访问请检查 VPN、代理服务器等设置，确保都是自动获取。

eduroam

同学出访其他参加 eduroam 联盟的学校时可使用 eduroam 免费上网。
登录账号为”学号@cuhk.edu.cn”(注意后缀)，密码为学校账号密码。

vpn

vpn 仅用于访问内网资源，不具有翻墙性质

网页版直接使用: https://vpn.cuhk.edu.cn/
客户端下载地址:

  • https://vpnsoft.cuhk.edu.cn (仅校内使用，无须登录)
  • https://vpn.cuhk.edu.cn/CACHE/stc/1/index.html (须登录)
  • https://cuhko365.sharepoint.com/sites/swcenter (须登录)

服务器地址：

  • 中国大陆: vpn.cuhk.edu.cn
  • 中国大陆以外：vpnhk.cuhk.edu.cn

使用学校账号登录即可使用。

网络测速

  • 校内测速: 10.10.10.10
  • 校外测速: https://www.speedtest.cn

文印服务

云打印网址: https://iprint.cuhk.edu.cn/ (网页版会有部分限制，例如上传的文件大小)

文印服务充值: 微信搜索微信公众号”香港中文大学深圳 ITSO”->文印服务->用户中心 (扫描是免费的)

校园常用系统概览

系统名称 网址 是否需要内网 介绍
综合评价招生报名系统 ugapply.cuhk.edu.cn 否 用于本科生综合评价方式招生报名
本科生录取查询系统 ug-inquiry.cuhk.edu.cn 否 查询录取证书寄送状态、奖学金申请状态、学校账号及初始密码
宿舍查询系统 apply.cuhk.edu.cn/matrix-base/apply/dorm_check 否 用于查询宿舍信息
迎新注册系统 orientation.cuhk.edu.cn 否 用于新生的迎新资料填写等工作
场所位置查询系统 https://booking.cuhk.edu.cn/a/office/mobile/home 是 访问时，如果跳转到了场地预定系统首页进行了统一认证，则需要在统一认证完成后再次访问该网址
网络终端管理平台 lan-portal.cuhk.edu.cn:8443/am/user/login/login.html 是 管理接入校园网的设备
SIS 学生信息系统 sis.cuhk.edu.cn 是(除特定时间外) 教务系统,选课,管理课程、成绩,学籍管理等
Blackboard Learn 在线教学平台 bb.cuhk.edu.cn 否 教师发布课程资料、发布测试、考试、讨论等
场地预定系统 booking.cuhk.edu.cn 是 校内除图书馆外的场地预定
自助缴费系统 pay.cuhk.edu.cn:3306 (特定时间开启) 用于学费、学杂费、大学生医保等费用的缴费
学生工作管理系统 stu.cuhk.edu.cn 是 用于检索管理学生信息;办理学生工作(勤工助学)、意外险(不参保申请)、学生证申请、本科生请假、本科生离校、学业导师、学生组织/社团管理、活动管理、校外导师管理、劳务费管理等事务
课程和教学评估系统 octe.cuhk.edu.cn 是 用于课程教学质量调查
实验室安全考试系统 labexam.cuhk.edu.cn 是 用于实验室安全考试
