# 港中深资源站

面向香港中文大学（深圳）学生的校园、学业与资源导航站。项目使用 Hexo 与 Butterfly 主题，部署到 GitHub Pages。

## 本地开发

```bash
npm ci
npm run dev
```

构建前会自动从 `source/course-resources/lanzou-manifest.json` 生成课程资料索引：

```bash
npm run build
```

课程资料文件仍由网盘托管；本站只维护可检索的目录、分类与入口，不提交资料文件本体。

### 课程资料索引同步

页面会优先读取 `course-index` 数据分支中的 `manifest.json`，读取失败时再回退到随网站发布的本地索引。因此仅更新资料索引不会触发 GitHub Pages 部署。

`.github/workflows/sync-course-index.yml` 每 6 小时以只读方式扫描蓝奏云目录：只同步文件名、大小、更新时间和下载入口，不会上传、删除或移动网盘文件。它只会为已确认含有文件的课程目录生成“打开课程文件夹”入口；空目录不会显示该入口。

首次启用或蓝奏云会话失效时，先在本机 Firefox 登录蓝奏云后台，然后更新仓库 Secret `LANZOU_CLASSIC_COOKIE`。工作流检测不到该 Secret 时会跳过，不会报错或部署网站。可选环境变量 `LANZOU_CLASSIC_ROOT_FOLDER_ID` 默认为当前课程资料根目录 `13698202`。

## 内容命名规范

文章标题与导航不是随意文案，而是站内检索、归档与长期维护的索引。新增或修改内容时遵循以下规则：

1. 使用简洁的中文标题，以“内容对象 + 文档类型”为基本结构，例如“跨学院转专业指南”“课程资料与电子课本”。
2. 操作类内容使用“指南”，推荐类使用“推荐”，集合类使用“汇总”，待办类使用“清单”；课程代码类使用“课程代码 + 主题”，例如“CEC1010 修读指南”。
3. 并列概念使用“与”，不使用 `&`；只有确有替代关系时才使用 `/`。
4. 英文缩写统一大写，并与中文之间保留一个空格；标题直接说明对象与用途，避免“如何快速高效地上手”这类泛化表述，例如“IT 指南”“SIS 使用指南”“SALL Centre 使用指南”“自由选修 PF 课程推荐”。
5. 不改动既有 `slug`，标题调整不得造成既有链接失效。

## 导航与页面一致性

每一个直接指向页面的导航项必须与目标页面标题完全一致。当前对应关系如下：

| 导航名称 | 路径 | 页面标题 |
| --- | --- | --- |
| 入学清单 | `/checklist/` | 入学清单 |
| 书院与住宿 | `/dorm/` | 书院与住宿 |
| 校园地图 | `/map/` | 校园地图 |
| 学校联系方式 | `/contact-school/` | 学校联系方式 |
| IT 指南 | `/guide-IT/` | IT 指南 |
| 课程资料与电子课本 | `/course/` | 课程资料与电子课本 |
| 重要资料汇总 | `/material/` | 重要资料汇总 |
| 社交媒体与宝藏资源 | `/social/` | 社交媒体与宝藏资源 |
| 关于本站 | `/about/` | 关于本站 |

“校园生活”“学业成长”“资源社区”是分组菜单，不对应单独页面；“学业”指向同名分类页。新增导航前，先确定页面标题，再复用该标题作为菜单名称。
