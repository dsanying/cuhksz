教科书与论文文献获取指南

原文链接：LGU生存指南（八） - 如何寻找和下载教科书和论文文献

免责声明

本文目的是在香港中文大学（深圳）图书馆无法找到对应资源的情况下，为读者提供额外的参考方法。作者尊重所有创作者的知识产权。部分网址可能需要特定网络环境访问，若主站无法访问，可尝试使用对应的镜像网站。

教科书获取途径

个人收集

课程资料/电子课本

英文教科书搜索路径

推荐搜索顺序：Z-Library → Anna’s Archive → Library Genesis → 直接Google（书名 + pdf）

主要资源网站

  • Z-Library：域名经常更换，需定期更新。教科书数据全面，但通常只有教材文本，没有配套的答案解析。可通过B站和X平台的官方账号获取最新域名。

  • Anna’s Archive：稳定、安全，数据量大。官方网站：https://annas-archive.org/
  • Library Genesis：历史悠久的教科书存储网站，甚至可找到1980年代的教科书。域名也经常变更，可参考官方网站：https://libgen.onl/library-genesis/

中文教科书搜索路径

推荐搜索顺序：Z-Library → 微信公众号 → 直接Google（书名 + pdf）

英文文献获取途径

搜索路径

推荐搜索顺序：Web-Science/Science Direct → Sci-hub → Google Scholar → Z-Library/Anna’s Archive/Library Genesis

主要资源网站

  • Web-Science/Science Direct：综合性强的文献检索工具，涵盖各领域文献。相比更专业的Pubmed/IEEE/ResearchGate等，综合体验更优。
  • Sci-hub：知名的文献获取网站，但域名长期不稳定。请留意最新的镜像地址。
  • Google Scholar：传统简洁的学术搜索引擎，UI简洁，使用体验极佳。官方网站：https://scholar.google.com/

中文文献获取途径

搜索路径

推荐搜索顺序：CNKI中国知网/万方数据 → iData → 科研通

主要资源网站

  • CNKI中国知网/万方数据：涵盖几乎所有中文文献的数据库。下载时需注意以高校或机构身份访问，可利用虚拟位置等方式利用不同图书馆的文献资源。
  • iData：被称为”CNKI中国知网的Sci-hub”，需注册账号，单日下载限制为2篇。
  • 科研通：学术界的文献获取平台。官方网站：https://www.ablesci.com/
